# 🍽️ Flavor Fusion - Your Culinary Playground!

**Flavor Fusion** is a full-stack web application designed for food lovers, home cooks, and recipe explorers. It brings together a dynamic, interactive platform where users can discover, share, and personalize recipes with ease. Built with **React, Node.js, Express.js, and MongoDB**, the app integrates external APIs and modern features to deliver a smooth and secure experience.

---

## 🚀 Live Demo

- **Project link:** https://favourfusion.netlify.app/


---

## ✨ Key Features

### 🔐 Secure Authentication
- JWT-based login system  
- Encrypted passwords  
- OTP-based password recovery

### 🍲 Recipe Management
- Full CRUD operations (Create, Read, Update, Delete)  
- Cloudinary image upload & management  
- Print-friendly recipe view  

### 📈 Smart Features
- Nutritional analysis using external APIs  
- Personalized meal planning based on dietary preferences  

### 🗣️ Intelligent Search
- Voice-based search  
- Text and ingredient-based search  

### 💬 Social Interactions
- Comment on recipes & reply to others  
- Rate and follow recipes  
- Get notified with a newsletter featuring top-rated content  

### 👤 Profile Management
- Edit your profile easily  
- Track your favorite recipes and interactions  

---

## 🧠 Tech Stack

- **Frontend:** React  
- **Backend:** Node.js + Express.js  
- **Database:** MongoDB  
- **Other Tools:** Cloudinary, JWT, OTP, API Integrations
